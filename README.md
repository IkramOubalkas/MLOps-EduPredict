# EduPredict

Plateforme intelligente de prediction du risque
d'abandon universitaire avec une approche MLOps.

## Technologies

- Python et scikit-learn
- Git et DVC
- MLflow
- FLAML et H2O AutoML
- Orange et KNIME
- SHAP, LIME et Fairlearn
- Prefect et Node-RED
- FastAPI et Streamlit
- Docker et Kubernetes
